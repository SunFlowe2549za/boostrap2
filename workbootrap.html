Exactly what was changed and why:
  • 1. Built on the Bootstrap Grid (container/row/col): สร้าง Section ใหม่ใต้ Carousel โดยใช้ .container และแบ่ง .row ออกเป็น 3 คอลัมน์ (.col-md-4) เพื่อให้จัดเรียงเนื้อหาได้อย่างเป็นระเบียบและรองรับ Responsive
  • 2. At least three components: นอกจาก Navbar และ Carousel (ที่มีอยู่เดิม) ได้เพิ่ม Cards 3 ใบลงใน Grid และเพิ่ม Modal (Popup) ผูกเข้ากับปุ่มบน Card เพื่อให้หน้าเว็บมี Component เชิงโต้ตอบครบถ้วน
  • 3. Utility classes used: ใช้คลาสอรรถประโยชน์ต่างๆ เช่น mt-5, mb-5, text-center, shadow-sm, border-0 และ h-100 เพื่อจัดการ Spacing, การจัดวางข้อความ และเพิ่มเงาให้สวยงามโดยไม่ต้องพึ่งพา Custom CSS มากเกินไป
  • 4. Custom CSS override: เขียนโค้ด <style> ในส่วน Head เพื่อทำการ Override คลาส .btn-primary ของ Bootstrap โดยเปลี่ยนสีพื้นหลังเป็นสีม่วง (Custom color) ปรับขอบให้มน (Pill shape) และใส่ Animation เมื่อนำเมาส์ไปชี้ (Hover effect)
  • 5. An AI log: เพิ่ม Card Component ชุดนี้ไว้ด้านล่างสุดของเว็บไซต์เพื่อบันทึก Prompts และสรุปสิ่งที่เปลี่ยนแปลงไป เพื่อให้ตรงตามเงื่อนไขของ Lab Assignment แบบ 100%
